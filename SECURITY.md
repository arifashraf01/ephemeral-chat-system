# Security Policy

## Supported Versions

Only the latest version of this project is supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| >= 1.0  | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

If you discover any security related issues, please email the maintainer instead of using the issue tracker. All security vulnerabilities will be promptly addressed.
