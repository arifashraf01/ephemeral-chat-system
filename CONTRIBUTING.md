# Contributing to Ephemeral Chat System

First off, thank you for considering contributing to the Ephemeral Chat System! It's people like you that make this tool great.

## How to Contribute

### 1. Report Bugs
If you find a bug, please create an issue with details on how to reproduce it, your environment, and any relevant logs.

### 2. Suggest Enhancements
We welcome ideas for new features or improvements. Open an issue and describe your idea in detail.

### 3. Pull Requests
- Fork the repository.
- Create a new branch for your feature or bugfix (`git checkout -b feature/your-feature-name`).
- Make your changes and commit them with a descriptive message.
- Push your changes to your fork.
- Submit a pull request to the `main` branch.

## Coding Standards
- We use `.editorconfig` to enforce consistent styles.
- Ensure your code is well-commented and clean.
- Write tests for your features if applicable.

Thanks again for your support!
